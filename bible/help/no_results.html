Why Are There No Results When Performing a Search?

Problem:

The BLB-CD always returns zero results when performing a word/Strong's search.

Cause:

This problem can be caused by one of two things.

  1. You have a pop-up blocker installed

  2. You are running Windows XP with Service Pack 2 installed.

Work-Around:

  1. If a pop-up blocker is installed, configure your pop-up blocker to allow pop-ups for the site, while viewing the main page for the CD.

  2. If Windows XP (Service Pack 2) is installed, use the following (more-involved) solution. Because some users have installed the BLB-CD to their hard drive, both solutions, for CD-ROM and hard drive, will be explained.

    Open Internet Explorer, then go to the 'Tools' menu at the top and select 'Internet Options' as seen below.


    Then choose the 'Advanced' tab and scroll down to the last section labeled 'Security'. The first two checkboxes should be labeled 'Allow active content to run from my CD-ROM' and 'Allow active content to run from My Computer'; these two options were installed with Service Pack 2 and are unchecked by default, disallowing active scripting to run from your hard drives or CD-ROM. Both checkboxes should be selected in order to allow the BLB CD to run from your CD-ROM and/or hard drive as seen below.

Caveats:

  1. Pop-up Blocker — There are no known caveats for the first solution.

  2. Service Pack 2/Internet Explorer —; By affecting this change (the second solution) you are defeating a security enhancement that Microsoft has installed. Prior to Service Pack 2, this feature was non-existent. To help reduce any security threats, only check the option for allowing active scripting to run from your CD-ROM and then only run the application from your CD-ROM. If you wish to run it from the hard drive, you will need to check the other option as well.
