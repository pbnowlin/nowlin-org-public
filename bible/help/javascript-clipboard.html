How to Enable the Copy to Clipboard Feature
Overview

One of the newer features on the Blue Letter Bible website allows users to more effeciently adapt Scripture references for their own purposes. This is performed through the use of the clipboard. When material is copied, it is placed into the clipboard, then the user may paste the contents of the clipboard into their own document. This FAQ shows users how to enable this feature for their own use. For instructions, please select the appropriate browser below:

  • Instructions for Internet Explorer 7 Users
  • Instructions for Firefox Users
Internet Explorer 7 Users

Enabling Internet Explorer 7 to allow the Copy to Clipboard feature to work is very simple. When you try to use the tools, you will be prompted with a window that says: Do you want to allow this webpage to access your clipboard? Click Allow access to enable the feature.


Firefox Users

In order for some of these new clipboard features to work properly for Firefox users, the browser needs to have permission to allow the Copy to Clipboard function work. Carefully, follow these steps to enable the Copy to Clipboard feature:

First, in Firefox's address bar, input the following text and press enter:

about:config


After doing this, you should see a list of the browser's preferences. Be careful not to edit any preferences other than what is mentioned in this tutorial. Now, right click anywhere on the list of preferences. When the dropdown menu appears, select New, then select Boolean from the next menu.


A new window will appear in which you can input text. Enter the following text and click OK:

signed.applets.codebase_principal_support


Make sure the value is set as true, which it should be by default. You can now navigate back to the Blue Letter Bible and utilize the Copy to Clipboard features of the site. This will also enable similar features from other websites to work.

When you attempt to use the Copy to Clipboard function on the site, you will be prompted one time to give Firefox permission to use this tool on the Blue Letter Bible. The window will look something like the following:


Before clicking OK, make sure you check the box that says "Remember this decision" (by doing this you will not be continually prompted; you may need to restart Firefox for the changes to take affect). Now you're ready to fully use the BLB's Copy to Clipboard function.
