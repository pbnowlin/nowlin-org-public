How to Use the Blue Letter Bible CD
What is in the Blue Letter Bible?

The Blue Letter Bible (BLB) is an internet site on the World Wide Web. It's internet address is https://www.blueletterbible.org. What you are viewing is a CD version of a small subset of the Blue Letter Bible website. This CD and the website are different primarily because:

  • The website is based on dynamic content that is added to on a periodic basis
  • CD technology requires certain "look and feel" adjustments
  • CD technology is not as feature rich as that which can be provided on the website
  • The CD is limited because of CD size restrictions. The web site is temendously larger than a CD.

The BLB CD was designed as a self-contained web site on a disc that does not require 'installation' on any computer/operating system. It was intened, initially, for the use of missionaries stationed in locations with no internet access. It is now available for the use of anyone that can make use of it. For software requirements and recommendations, please see our brief explanation Briefly, if the computer/operating system runs a web browser and has a CD-Rom drive, the BLBCD should run on it. It can be run directly from the CD or be copied directly to the hard drive.

Primary Bible

The Blue Letter Bible CD provides, as it's primary Bible, an 18th century edition of the "King James Version" (for more information on why the KJV see this page). Additional versions or translations are available to view for verse by verse comparison (as explained below).

How do you use all the above features?

The basic idea is that ALL the features described above are available as you read the Blue Letter Bible, by clicking various buttons located to the left of every verse. For almost every verse in the Blue Letter Bible, there are at least there are at leaset three things you can do:

  1. Click on the button at the far left to see suggested Scriptures that relate to the verse. See our tutorial for more information regarding the usage of this feature.

  2. Click on the button for Greek/Hebrew and concordance/lexicon. The verse will be re-displayed along with the Greek/Hebrew text. Click on any English word within the table to see search results for that English word. You will see how the English word is used in the KJV translation, as well as dictionary entries discussing that word. Or, click on the Strong's number next to the English word. It will give you a concordance of the usage of the original language word, and a lexicon entry including a pronunciation guide. See our tutorial for more information regarding the usage of this feature.

  3. Click on the button for a list of all text commentaries and study materials relating to the selected verse. This is the same action as clicking on the actual Bible verse reference (such as Jhn 3:16). You may browse through this list, choose one, then click on the View Commentary button which appears. A new page displaying your choice will then appear. After viewing to your choice, you may go back to the menu window, and make another choice! See our tutorial for more information regarding the usage of this feature.

  4. Click on the button for a link to images or maps that pertain to the chosen passage—this feature will not be available for all verses. See our tutorial for more information regarding the usage of this feature.

  5. Click on the button for different versions / translations—including Holman Christian Standard Bible, Webster's, Young's, Darby's, American Standard Version, Hebrew Names Version, Revised Standard Version, and the Vulgate. See our tutorial for more information regarding the usage of this feature.

  6. Click on the button for a list of dictionary entries pertaining to the selected verse. See our tutorial for more information regarding the usage of this feature.
