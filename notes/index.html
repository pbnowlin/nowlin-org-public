Notes

Overview

A scratchpad that keeps everything on this device. Notes live in this browser's local storage — they are never uploaded, never synced, and no account is involved. Nothing here can be read from anywhere else.

Because there is no server, the flip side matters: clearing your browser data, using private browsing, or switching to another device or browser means these notes are gone. Export a backup if a note matters.

Writing notes

  • Title and content — either one alone is enough to save.
  • Folder — optional. Start typing and matching folders are suggested; pick one to reuse its exact spelling, or type a new name to create a folder.
  • Self-destruct — every note is given a countdown, 30 days by default. Use a preset, type any number of hours, or tick Never delete to keep it indefinitely.
  • Notes over ten lines are shortened in the list. Tap one to expand it.
  • Copy puts a note's full text on your clipboard, including the part hidden when it's shortened. The title is not included.

Password protection

Under Settings you can encrypt every note with a password. Encryption happens in this browser using a key derived from your password, so what's stored on disk is unreadable without it.

The minimum is twelve characters, and there are no rules about symbols or digits — length is what actually makes a password hard to guess. A short phrase of ordinary words is a good choice. The meter under the field shows an upper bound on how strong it is, and prices a word phrase per word rather than per character, so it stays honest about phrases.

There is no password reset and no recovery, because there is nothing anywhere that could perform one. Forgetting the password means those notes are gone permanently. The key is held in memory only, so reloading the page locks them again.

An unlocked page locks itself again after fifteen minutes without typing or tapping — the countdown sits next to Protected under Settings, and you can change the interval or switch it off there.

Backups

JSON is the backup format — it's the only one that can be imported back in, and it preserves folders and countdowns exactly. If password protection is on, the exported file stays encrypted and needs that password to import.

CSV is for reading, not restoring — a plain table you can open in a spreadsheet. It cannot be imported, and it is always written in plain text, so treat that file as unprotected.

Questions

A note vanished — why? Its countdown ran out. Expired notes are removed when the page is open, so one that lapsed while the page was closed disappears the next time you visit.

Can I get a deleted note back? No. Deleting and expiry are immediate and permanent, which is why Delete asks for a second tap.

What is a "Damaged note"? A note whose stored data was corrupted and can no longer be decrypted, even with the right password. Its contents are unrecoverable; you can delete the entry to clear it.

The page says my password data is missing — are my notes gone? No. Notes and password data are kept in two separate browser storage entries, and one can be cleared without the other. Your notes are still encrypted on the device and still open with your password; what is missing is the part this page needs to turn that password into a key. Editing switches off so nothing writes over them. Save a raw copy, then import any earlier JSON backup made while protection was on — that restores the missing part.

Do these sync to my phone? No. Each browser on each device keeps its own separate set. Export from one and import into the other to move notes across.

Is anything sent over the network? No. The page makes no requests with your notes, and spellchecking is switched off on every field so what you type is not sent to a spellcheck service either. Once loaded it works offline.

⚠ Encrypted notes, missing password data

Your notes have not been lost. They are still encrypted on this device, and they are still readable with the password — what is missing is the salt and verifier this page needs to derive the key from it. That data lives in a separate browser storage entry, which can be cleared or damaged on its own.

Editing is switched off so nothing overwrites the encrypted data. Export a raw copy first — if you have an earlier JSON backup, importing it restores the missing part and your notes open again.
